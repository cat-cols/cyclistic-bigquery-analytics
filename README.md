# cyclistic-bigquery-analytics

This project was originally completed as part of the Google Data Analytics Professional Certificate capstone and later adapted into a GitHub portfolio project using BigQuery SQL.

BigQuery SQL analysis of Cyclistic bike-share data comparing casual riders and annual members to uncover usage patterns and membership growth opportunities.

Primary Category: Data Analyst / BI
Secondary Category: SQL Analytics
Stack: BigQuery, SQL, Tableau/Power BI, Google Data Analytics Capstone
Dataset: Cyclistic bike-share
Portfolio Status: Featured or Supporting
